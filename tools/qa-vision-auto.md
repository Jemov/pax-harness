# Автоматическое определение изображений — QA

Pax Harness 1.23.0 и AI fine tuning 2.4.0; Pax Universe 0.31.6.

По умолчанию выбран режим Auto. Каталог проверяет именно входные модальности; имя модели и генерация картинок не считаются подтверждением. При неизвестной поддержке SDK отправляет маленькую PNG с шестью случайными цифрами. Ответ должен совпасть; HTTP 200 сам по себе не подтверждает зрение. Запрос ограничен 2 048 выходными токенами с учётом рассуждения и 30 секундами. Используются текущая модель, подключение и штатный маршрут. Подтверждение сохраняется на сутки для API/model; явный отказ — на час. Временный сбой не объявляется отсутствием поддержки.

Проверено на deepseek/deepseek-v4.1-flash:
- Неизвестные модальности API → успешная автоматическая визуальная проверка → настоящий снимок игры → ответ с описанием Земли.
- Повторный снимок использовал сохранённый результат, дополнительного probe-запроса не было.
- Полностью выключенный профиль генерации, vision_mode=auto: автоматическая проверка прошла; модель точно прочитала независимые случайные цифры пользовательского вложения. Цифр не было в тексте запроса. Проверочный запрос: 310 входных и 229 выходных токенов, включая рассуждение. Все запросы использовали 4.1.
- При неподтверждённой проверке исходный текст отправился; модель сообщила, что не видит картинку. В тестах также проверен явный отказ text-only API и повтор текста после отказа изображения.
- Холодный перезапуск сохранил подтверждение, вложение и статистику. Тестовый мир остался на дне 27. Исходные параметры генерации восстановлены; режим Auto оставлен. Модель не закреплялась и не подменялась.
- RU → EN → RU в новом списке: выбранный режим сохраняется, подписи и пояснения помещаются. Длинные подписи переносятся. Проверено также в узкой форме 300 px.

Нативный check обоих установленных модов: 0 ошибок, 0 предупреждений. Это результат проверки модов, а не утверждение об отсутствии посторонних сообщений в общем журнале игры.
