# Визуализации и источники данных

Диаграммы — нативные элементы Godot, без HTML и внешних картинок. В ответе
используется блок `pax-chart` с проверяемой структурой данных. Агент вызывает
`charts.describe` для одного вида и получает его схему по необходимости.

| Задача | Поддерживаемые виды |
| --- | --- |
| Сравнение и состав | bar, column, stacked_bar, stacked_column, waterfall |
| Динамика и зависимости | line, area, stacked_area; линейная или плавная кривая |
| Парные и тройные показатели | scatter, bubble |
| Распределения | histogram, boxplot, density, violin, ridgeline |
| Доли | pie, donut, treemap |
| Матрицы и профили | heatmap, radar |
| География | choropleth, cartogram |
| Потоки | sankey |
| Проекты, связи и иерархии | gantt, network, sunburst, tree, icicle |
| Дополнительные сравнения | combo, interval, errorbar, dumbbell, slope, bump, parallel, small_multiples |
| Дополнительная география и календарь | symbol_map, flow_map, calendar_heatmap |

Это 39 видов. Родственные варианты вроде календарной тепловой карты можно
выразить матрицей; они не требуют нового исполняемого кода. Специализированные
дендрограммы, Andrews Curves и т. п. пока не имеют отдельного рендерера.
Наличие или отсутствие данных в базовой игре не является запретом для модов.

Подписи измеряются по используемому шрифту и переносятся. Высота графика и
легенды учитывает длинные названия. В маленьких ячейках и плотных категориях
используются номера с полной расшифровкой под графиком; подробные значения
также доступны при наведении. У осей с большим количеством точек показывается
разреженная шкала, а не все подписи одновременно.

`charts.function` рассчитывает полиномы, степени, параболу, гиперболу, синус,
косинус, тангенс, экспоненту, логарифм, логистическую кривую и составные формулы.
Разрешены арифметика, x, параметры и ограниченный набор математических функций;
исполнение скриптов отсутствует. Неопределённые точки пропускаются, ветви у
обнаруженных полюсов разделяются. Это сценарный расчёт, не игровая история.

Границы: до 241 точки линии или рассеяния, 60 категорий, 4 рядов; распределения
до 1000 наблюдений суммарно; до 64 регионов карты с 12000 вершинами суммарно.
Большие данные фильтруются/группируются по задаче, с указанием охвата.

Масштаб 100–400 % меняется кнопками или Ctrl + колесо, средняя кнопка мыши
перемещает увеличенный график. «Фильтр» открывает поиск, выбор рядов и параметры
вида. Санки и сеть умеют подсвечивать связанные пути и закреплять выбор щелчком.
Sunburst раскрывает ветвь по щелчку; центр и кнопка корня возвращают всю иерархию.
▶ повторяет короткую анимацию. В меню ⋯ её можно отключить или сбросить фильтры.
Фильтры меняют только отображение и сохраняют исходные данные сообщения.

Gantt принимает до 64 задач с числовыми датами в общей единице и ацикличными
зависимостями; равные начало и конец означают веху. Network принимает до 64 узлов
и 128 связей, включая циклы и отдельные узлы. Sunburst принимает до 128 узлов
и 8 уровней; значения задаются только листьям, суммы родителей вычисляются.

## Что требуется от данных

- Density/Violin/Ridgeline — отдельные сравнимые наблюдения одного показателя.
  Рендерер рассчитывает Gaussian KDE, показывает n и предупреждение для n<20.
  Уровни предприятий пригодны для распределения уровней предприятий; средние
  зарплаты компаний — для распределения средних зарплат компаний. Ни то ни
  другое не является выборкой индивидуальных доходов жителей.
- Box Plot — пять чисел, рассчитанных из выборки по указанному правилу квартилей.
- Sankey — реальные направленные потоки в одинаковых единицах за один период.
  Суммарный экспорт не раскрывает торговых партнёров. Остаток нельзя выдумывать.
- Heatmap — матрица; пропуск null остаётся пропуском. Для корреляции нужны пары
  наблюдений и расчёт коэффициента.
- Radar — явно обоснованная общая нормализованная шкала.
- Choropleth — действительные контуры регионов. `charts.map` извлекает упрощённые
  границы из уже загруженной домашней карты по общей растровой сетке. Cartogram здесь — подписанная
  схематичная сетка равных плиток, а не искажение площади территории.

## Инструменты и контекст

- `analytics.read`: страница предприятий, провинций, ресурсных потоков, стран
  или сохранённой статистики. Названия модовых ресурсов и типов не ограничены
  ванильным списком. Этот адаптер экономики относится к стране игрока.
- `analytics.sources`: доступные модовые источники без самих наблюдений.
  Параметр source раскрывает схему одного источника.
- `analytics.query`: один источник, фильтры, страница до 200 строк.
- `charts.map`, `charts.function`: полный результат сохраняется в вызове
  инструмента, а в контекст модели передаются сводка и display_ref. Блок
  `{"tool_call_id":"..."}` внутри pax-chart разрешается только по успешному
  результату в том же сообщении. Это работает после загрузки партии.

Markdown-экспорт раскрывает ссылки в полные данные; текстовый экспорт сохраняет
значения и источник. Для точечного изучения большого результата есть trace.read.

## Подключение других модов

Встроены адаптеры известных версий Сферы Дайсона, Pax Corporations,
«Переработки экономики» и Occupation Rework. Они читают проверенные методы и
поля; отсутствие или неготовность мода выдаёт отдельную ошибку. Произвольные
методы по имени, выбранному моделью, не вызываются. Покупки, строительство и
изменение политики через эти адаптеры отсутствуют.

Для нового мода можно зарегистрировать источник без изменения файлов харнеса:

```gdscript
var h = Pax.get_mod("pax_harness")
if h != null and h.has_method("register_analytics_source"):
    h.register_analytics_source("my_mod.production", "Производство",
        "Текущие наблюдения производства по заводам",
        {"type":"object", "properties":{"resource":{"type":"string"}},
         "required":["resource"], "additionalProperties":false},
        _read_production)

func _read_production(game: RefCounted, parameters: Dictionary, page: Dictionary) -> Dictionary:
    # Использовать переданный текущий game, фильтровать до разбиения на страницы.
    # rows — максимум page.limit строк. Никаких шагов симуляции или изменений мира.
    var matching: Array = actual_rows(game, parameters.resource)
    var rows: Array = matching.slice(page.offset, page.offset + page.limit)
    return {"rows":rows, "source":"Производство · фактическая дата и охват",
        "has_more":page.offset + rows.size() < matching.size(),
        "next_offset":page.offset + rows.size()}
```

Это контракт для доверенного кода установленного мода, а не песочница для
произвольных скриптов. Callback обязан быть синхронным, ограниченным по времени
и только читать данные. Аргументы проверяются по зарегистрированной схеме;
ответ ограничен 256 КиБ и JSON-типами. Регистрация не читает наблюдения, не
меняет сохранение и не добавляет массивы в каждый запрос модели.
