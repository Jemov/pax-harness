# Запись до нажатия Стоп — QA

Pax Harness 1.24.1, Pax Universe 0.31.6. Убрана автоматическая остановка по времени, ограничение записываемого буфера, 30 секунд в WAV и метаданных, прежние ограничения размера WAV/base64. Ограничения самого формата RIFF сохранены. Проверки изображений и лимиты ответов API не менялись.

В живом клиенте запись оставалась активной на 33.22 секунде (1 592 832 кадра) и завершилась только после повторного нажатия микрофона. Микрофонное тестовое аудио не отправлялось провайдеру и удалено из локального хранилища.

Контрольная запись — 77.06 секунды, фраза находится после 70 секунд тишины. После нормализации — 2 465 918 байт, больше прежнего лимита 2 МиБ. Файл сохранился и был доступен после холодного запуска. Полная передача штатному распознавателю не разобрала речь; адаптер теперь последовательно подаёт короткие участки после остановки записи, пропускает тишину и соединяет перекрывающийся текст. Исходный WAV сохраняется целиком.

47 автоматических проверок аудио: запись не завершается по таймеру, Stop возвращает все 71 секунду и последний образец, длинный WAV сохраняется через JSON, запрос/исправление формата не теряют большой input_audio, длинная речь обрабатывается четырьмя последовательными частями, повторы на стыке удаляются, речь после 70 секунд достигает ASR, исходные обработчики восстановлены, отмена не отправляет поздний результат. Регрессии: provider protocol, chat UI, localization.

Живая проверка после холодного запуска: фраза из конца 77-секундной записи распознана целиком, audio_route=transcribed, DeepSeek 4.1 ответил `5`, status=complete. День 27 сохранён, распознавание и запись остановлены, исходный обработчик recognized восстановлен.
